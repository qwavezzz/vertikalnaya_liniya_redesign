# «Вертикальная линия» — редизайн

Рабочие материалы редизайна сайта [vl63.ru](https://vl63.ru/).

## Варианты для клиента

Три самостоятельных сайта с разным дизайном. Для отправки клиенту достаточно трёх файлов — каждый открывается в браузере без интернета, установки и сервера:

- [Вариант 1 — Архитектурный альбом](variant-1.html)
- [Вариант 2 — Геометрия света](variant-2.html)
- [Вариант 3 — Свет в пространстве](variant-3.html)

Каждый файл занимает около 5 МБ и содержит 26 страниц: главную, каталог и шесть услуг, проекты с отдельными страницами, журнал и статьи, компанию, партнёров, материалы, контакты, конфиденциальность и страницу 404. Работают переходы, история браузера, мобильное меню, поиск, фильтры, увеличение фотографий и вопросы-ответы. Фотографии и шрифт встроены. Форма проверяет поля и готовит письмо для почтовой программы; серверной отправки нет.

Версии с обычными отдельными HTML-страницами находятся в [redesign/variant-1](redesign/variant-1/index.html), [redesign/variant-2](redesign/variant-2/index.html), [redesign/variant-3](redesign/variant-3/index.html). Для передачи такой версии нужна вся папка соответствующего варианта. [redesign-options.html](redesign-options.html) служит общей страницей входа.

В интерфейсе GitHub HTML показывается как исходный код; для просмотра используйте **Download raw file**. Публикация через GitHub Pages пока не настроена.

## Сборка и проверка

Редактируемые исходники: `redesign/build.py`, `content.py`, `styles.css`, `site.js` и `launch.html`. Генератор на Python 3 собирает все три автономных файла и обычные многостраничные версии:

```bash
python -X utf8 redesign/build.py
```

Проверка ссылок, маршрутов, действий и адаптива: `python -X utf8 redesign/verify.py`. Для неё нужны пакет Python `websockets` и Chromium; путь к браузеру задаётся переменной `REDESIGN_CHROME`. Результаты и снимки сохраняются в игнорируемой папке `.impeccable/site-checks/`.

## Локальная копия текущего сайта

```bash
python site-archive/serve.py
```

Откройте:

- http://127.0.0.1:4173/ — текущий сайт в локальном архиве;
- http://127.0.0.1:4173/archive-index.html — список материалов с поиском;
- http://127.0.0.1:4173/photo-index.html — подборка фотографий для редизайна.

Для просмотра достаточно Python 3 и браузера. Joomla и база данных не требуются. Сервер запускается только на этом компьютере; остановка — Ctrl+C.

Архив содержит статические публичные материалы и исходные ответы сайта. Полноразмерные фотографии занимают существенный объём. Одинаковые файлы в `originals/` и `public/` хранятся в Git как общие объекты, но в рабочей папке занимают место отдельно.

Админка, база данных, неопубликованные записи и серверная обработка форм в архив не входят. Это подготовка к редизайну, а не реализация нового дизайна.

Подробнее: [инструкция архива](site-archive/README.md), `site-archive/crawl-report.json` и `site-archive/file-audit.json`. Ошибки и недоступные исходные материалы отражаются в отчётах.

## Восстановить страницы из скачанных оригиналов

```bash
python -m pip install --target site-archive/.deps -r site-archive/requirements.txt
python site-archive/scripts/archive_site.py --offline
python site-archive/scripts/build_photo_index.py
```

`--offline` не обращается к исходному сайту. Вспомогательные зависимости, временные журналы и локальные настройки в репозиторий не включены.

# Локальный архив «Вертикальная линия»

Источник: https://vl63.ru/. Дата сохранения: 15 сентября 2026.

Это статическая копия публичной части сайта для просмотра, работы с фотографиями и подготовки редизайна. Она сохраняет доступный HTML, CSS, JavaScript и изображения. Админка, база данных и серверные PHP-файлы в неё не входят.

## Открыть сайт

Из рабочей папки проекта:

```powershell
python site-archive/serve.py
```

Открыть **http://127.0.0.1:4173/**.

Список сохранённых материалов с поиском по названию: **http://127.0.0.1:4173/archive-index.html**.

Каталог фотографий с поиском и скачиванием оригинала: **http://127.0.0.1:4173/photo-index.html**.

Если порт занят:

```powershell
python site-archive/serve.py --port 4174
```

Сервер слушает только `127.0.0.1`. Для остановки нажмите Ctrl+C в окне сервера. Для просмотра нужны Python 3 и браузер; установка Joomla, PHP и базы данных не требуется. Прямое открытие `public/index.html` через `file://` не поддерживается: внутренние пути рассчитаны на локальный HTTP-сервер.

## Где лежат материалы

| Путь | Содержание |
| --- | --- |
| `public/` | Сайт с локальными ссылками и ресурсами |
| `public/images/` | Фотографии и изображения из исходной папки images |
| `public/media/` | Сохранённые файлы компонентов, включая изображения материалов K2 |
| `content/pages.json` | Тексты, HTML содержимого, SEO-поля, исходные URL, типы страниц, ссылки на фото |
| `content/pages.csv` | Реестр страниц для Excel и ручной разметки |
| `content/articles/` | Читаемые текстовые копии материалов в Markdown |
| `content/images.json` | Изображения, контрольные суммы и связь с материалами |
| `content/images.csv` | Реестр всех загруженных изображений |
| `content/photo-selection.json` | Кандидаты фотографий для редизайна, без одинаковых по содержимому файлов |
| `content/redirect-map.csv` | Исходные адреса и заготовка сопоставления с адресами нового сайта |
| `originals/` | Неизменённые ответы источника: файлы `.bin` и метаданные `.json` |
| `manifest.json` | Сопоставление исходного URL, локального пути и сохранённого оригинала |
| `crawl-report.json` | Фактические объёмы, ошибки скачивания и ограничения охвата |
| `evidence/` | Скриншоты и свидетельства определения CMS |
| `TECHNICAL-AUDIT.md` | Движок, ограничения копии и подготовка переноса данных |

Папка изображений содержит и фотографии работ, и интерфейсные картинки. Для отбора используйте `images.json`: поле `used_in_content` связывает картинку с материалами. В K2 встречаются разные размеры одного фото; число файлов не равно числу уникальных работ.

`content_html_original` сохраняет HTML выбранной содержательной области. `content_html_local` содержит переписанные локальные пути. Это материал для импорта, а не готовый проверенный формат новой CMS: перед публикацией HTML нужно очистить по разрешённому набору тегов и связать изображения с новой медиатекой.

## Как устроена копия

- Страницы собраны по ссылкам реального сайта. Аномальная `sitemap.xml` не использовалась как список обхода.
- Сохранённые внутренние ссылки ведут в архив. Для страниц за пределами охвата показывается локальное пояснение.
- Подключённые изображения, стили и библиотеки скачаны, если были доступны источнику. Ошибки перечислены в `crawl-report.json`.
- Формы локально не отправляются. Комментарии, рейтинг и иные операции, которым нужен сервер Joomla, не воспроизводят серверное действие.
- Аналитические скрипты удалены из локального HTML. Политика ресурсов блокирует фоновые внешние подключения.
- Внешние видео и виджеты заменены явной ссылкой. Для перехода на внешний сайт нужен интернет.
- Длинные пути и адреса с параметрами получают устойчивое локальное имя; оригинальный адрес сохранён в реестре.

## Повторное сохранение

Скрипт выполняет только GET-запросы к публичным страницам и подключённым ресурсам. Он не входит в админку, не отправляет формы и не считывает закрытую базу.

```powershell
python -m pip install --target site-archive/.deps -r site-archive/requirements.txt
python site-archive/scripts/archive_site.py
python site-archive/scripts/build_photo_index.py
```

Повторный запуск использует уже скачанные оригиналы из `originals/`. Это позволяет достроить тот же снимок после сбоя. Для нового снимка на другую дату создайте отдельную папку архива; не смешивайте даты удалением отдельных записей из кэша.

Пределы обхода: 420 страниц, 3500 ресурсов, ориентир 600 МБ и до 12 МБ на один файл. Фактически пропущенные адреса перечисляются в `crawl-report.json`; успешный запуск не означает полного экспорта базы данных.

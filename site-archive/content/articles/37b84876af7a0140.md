# Бассейн в "Альтер Эго" с натяжными потолками с напечатанным фотоизображением неба с облаками.

Источник: https://vl63.ru/news/item/182-25.html

Для реализации нового проекта "Альтер Эго" была привлечена компания "Вертикальная линия", которая установила в новом бассейне натяжные потолки с фотопечатью неба с облаками по периметру.
Натяжной потолок общей площадью около 150 квадратных метров состоит из 3-х частей натяжного потолка по 50 кв.м, разделенных специальным профилем.

В
натяжные потолки с напечатанным изображением
неба на белой матовой пленке установлено 46 светильников и 16 вентиляционных диффузоров диаметром 320 мм.
